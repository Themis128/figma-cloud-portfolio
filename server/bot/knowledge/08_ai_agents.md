# AI Agent Templates

The portfolio features an AI Agent Template Browser at /agents/ with 5 pre-built agent templates:

## 1. Basic Chatbot (Beginner Level)
A conversational AI chatbot template for getting started with AI agent development.
**Category**: Conversational AI

## 2. Content Writer (Intermediate Level)
An AI agent that generates blog posts, articles, and marketing copy with customizable tone and style.
**Category**: Content Generation

## 3. Data Analyzer (Advanced Level)
An intelligent agent for dataset analysis, generating insights, and creating data visualizations.
**Category**: Data Analysis

## 4. Customer Support Agent (Intermediate Level)
An AI agent for handling customer inquiries, troubleshooting issues, and providing support.
**Category**: Customer Support

## 5. Code Reviewer (Advanced Level)
An AI-powered code review agent that checks for bugs, security vulnerabilities, and best practices.
**Category**: Code Quality

## About the Agent System
Each template includes complete workflow configurations with nodes, connections, LLM configurations, features, and use cases. Templates can be browsed, searched, filtered by category, and cloned for customization.
